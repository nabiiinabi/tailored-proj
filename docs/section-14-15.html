Does the Prior Change the Conclusion?

Last updated

October 16, 2026

Do these three priors lead to the same conclusion?

The three posterior means are:

  • Beta(3, 7) prior gives a Beta(12, 18) posterior, with mean 0.40.
  • Beta(1, 1) prior gives a Beta(10, 12) posterior, with mean 0.455.
  • Beta(7, 3) prior gives a Beta(16, 14) posterior, with mean 0.533.

Their probabilities that \(p\) is below 0.50 are also different:

  • Under Beta(12, 18): \(P(p < 0.50 \mid y) \approx 0.868\)
  • Under Beta(10, 12): \(P(p < 0.50 \mid y) \approx 0.668\)
  • Under Beta(16, 14): \(P(p < 0.50 \mid y) \approx 0.356\)

What each prior concludes

The lower-pass analysis suggests that \(p\) is probably below 0.50.

The neutral analysis also leans below 0.50, but the evidence is less decisive.

The higher-pass analysis leans the other way. Its posterior mean is 0.533, so about 64.4% of that posterior lies above 0.50. That is a tilt toward a higher pass rate, not a strong conclusion that \(p\) exceeds one half.

All three analysts observed the same movies. Their conclusions differ because 20 observations are not enough to overwhelm different prior beliefs.

This is why prior sensitivity analysis matters. A Bayesian analysis should not hide the effect of the prior. It should examine whether reasonable alternatives lead to substantially different conclusions.

If the conclusion remains stable across multiple defensible priors, it is relatively robust. If the conclusion changes, the honest conclusion may be that the current data are not strong enough to settle the question.

The three curves are the posteriors after the same 9 passes and 11 failures. The vertical line marks \(p = 0.50\).

// Three posteriors after 9 passes and 11 failures, and P(p < 0.50 | y)
{
  const passes = 9;
  const failures = 11;
  const priors = [
    {name: "Lower-pass", alpha: 3, beta: 7, stroke: "#2c3140"},
    {name: "Neutral", alpha: 1, beta: 1, stroke: "#5c5660", dash: "4,3"},
    {name: "Higher-pass", alpha: 7, beta: 3, stroke: "#b32b2f"}
  ];

  // Log of the gamma function, using the Lanczos approximation
  // (Lanczos 1964, https://doi.org/10.1137/0701008).
  // The next figure on this page uses a sample of 500 movies.
  // That needs Γ(α + β + n), past Γ(171), which JavaScript stores as Infinity.
  // Both figures therefore use logs instead of gamma values.
  function logGamma(z) {
    const c = [
      0.99999999999980993,
      676.5203681218851,
      -1259.1392167224028,
      771.32342877765313,
      -176.61502916214059,
      12.507343278686905,
      -0.13857109526572012,
      9.9843695780195716e-6,
      1.5056327351493116e-7
    ];
    if (z < 0.5) return Math.log(Math.PI / Math.sin(Math.PI * z)) - logGamma(1 - z);
    z -= 1;
    let x = c[0];
    for (let i = 1; i < c.length; i++) x += c[i] / (z + i);
    const t = z + 7.5;
    return 0.5 * Math.log(2 * Math.PI) + (z + 0.5) * Math.log(t) - t + Math.log(x);
  }

  // Height of the Beta(a, b) curve at p = x. Outside 0 to 1, the height is 0.
  function betaDensity(x, a, b) {
    if (!(x > 0 && x < 1)) return 0;
    const logB = logGamma(a) + logGamma(b) - logGamma(a + b);
    const density = Math.exp((a - 1) * Math.log(x) + (b - 1) * Math.log(1 - x) - logB);
    return Number.isFinite(density) ? density : 0;
  }

  // Chance that p is below x. For whole-number parameters this is a binomial sum.
  function betaCDF(x, a, b) {
    if (x <= 0) return 0;
    if (x >= 1) return 1;
    const total = a + b - 1;
    let sum = 0;
    for (let k = a; k <= total; k++) {
      let logCoefficient = 0;
      for (let i = 0; i < k; i++) logCoefficient += Math.log(total - i) - Math.log(i + 1);
      sum += Math.exp(logCoefficient + k * Math.log(x) + (total - k) * Math.log(1 - x));
    }
    return Math.min(1, Math.max(0, sum));
  }

  // Points on that curve, from p near 0 to p near 1.
  function betaCurve(a, b) {
    return Array.from({length: 201}, (_, i) => {
      const p = i / 200;
      const x = Math.min(1 - 1e-6, Math.max(1e-6, p));
      return {p, density: betaDensity(x, a, b)};
    });
  }

  const curves = priors.map(prior => {
    const postAlpha = prior.alpha + passes;
    const postBeta = prior.beta + failures;
    return {
      ...prior,
      postAlpha,
      postBeta,
      mean: postAlpha / (postAlpha + postBeta),
      belowHalf: betaCDF(0.5, postAlpha, postBeta),
      curve: betaCurve(postAlpha, postBeta)
    };
  });

  const plot = Plot.plot({
    width: Math.max(280, width - 4),
    height: 360,
    marginTop: 16,
    marginRight: 16,
    marginBottom: 48,
    marginLeft: 52,
    x: {
      label: "Population proportion, p",
      domain: [0, 1],
      ticks: [0, 0.2, 0.4, 0.6, 0.8, 1]
    },
    y: {label: null, grid: true, nice: true},
    marks: [
      ...curves.map(d => Plot.line(d.curve, {
        x: "p",
        y: "density",
        stroke: d.stroke,
        strokeWidth: 2.25,
        strokeDasharray: d.dash
      })),
      Plot.ruleX([0.5], {stroke: "#8a837c"}),
      Plot.ruleY([0])
    ],
    style: {
      background: "transparent",
      color: "#15151E",
      fontFamily: "Helvetica, sans-serif",
      fontSize: "13px"
    }
  });

  const bits = curves.map(d => `${d.name} ${ (d.belowHalf * 100).toFixed(1) }%`);

  return html`<div class="binomial-figure">
    <p class="binomial-ylabel">Density</p>
    ${plot}
    <p class="binomial-readout">The posterior probability that <em>p</em> is below 0.50 is <strong>${bits[0]}</strong>, <strong>${bits[1]}</strong>, and <strong>${bits[2]}</strong>.</p>
    <p class="binomial-legend"><span class="swatch swatch-other" style="margin-left:0"></span> Lower-pass <span class="swatch swatch-max"></span> Neutral <span class="swatch swatch-observed"></span> Higher-pass</p>
  </div>`;
}

What Happens When We Observe More Movies?

The influence of the data depends partly on the sample size.

Recall that the weight given to the data in the posterior mean is:

\[ \frac{n}{\alpha + \beta + n} \]

As \(n\) increases,

\[ \frac{n}{\alpha + \beta + n} \]

approaches 1. At the same time, the prior weight

\[ \frac{\alpha + \beta}{\alpha + \beta + n} \]

approaches 0.

The same pass rate, a larger sample

Suppose two samples both have pass rates close to 45%.

A sample with 9 passes out of 20 provides some evidence about \(p\), but its likelihood is fairly wide.

A sample with 90 passes out of 200 has the same observed proportion, but it provides much stronger evidence. Its likelihood is narrower because many more observations support the estimate.

As the sample grows, posteriors produced by different priors tend to move closer together. The data increasingly dominate the starting beliefs. The balance between the prior and the data changes as the amount of evidence changes.

Choose a sample size. Each sample keeps a pass rate near 45%. The three posterior curves narrow and move toward one another as the sample grows.

// Bigger samples that still have a pass rate near 45%.
viewof sampleSize = Inputs.radio(
  ["20 movies", "50 movies", "100 movies", "500 movies"],
  {label: "Sample size", value: "20 movies"}
)
// The same three priors, updated by larger samples with a pass rate near 0.45
{
  const n = Number(sampleSize.split(" ")[0]);
  const passes = Math.round(0.45 * n);
  const failures = n - passes;
  const rate = passes / n;
  const priors = [
    {name: "Lower-pass", alpha: 3, beta: 7, stroke: "#2c3140"},
    {name: "Neutral", alpha: 1, beta: 1, stroke: "#5c5660", dash: "4,3"},
    {name: "Higher-pass", alpha: 7, beta: 3, stroke: "#b32b2f"}
  ];

  // Log of the gamma function, using the Lanczos approximation
  // (Lanczos 1964, https://doi.org/10.1137/0701008).
  // A sample of 500 movies needs Γ(α + β + n), which is past Γ(171).
  // JavaScript cannot store a number that large: it becomes Infinity.
  // The density is therefore built from logs, not from the gamma values.
  function logGamma(z) {
    const c = [
      0.99999999999980993,
      676.5203681218851,
      -1259.1392167224028,
      771.32342877765313,
      -176.61502916214059,
      12.507343278686905,
      -0.13857109526572012,
      9.9843695780195716e-6,
      1.5056327351493116e-7
    ];
    if (z < 0.5) return Math.log(Math.PI / Math.sin(Math.PI * z)) - logGamma(1 - z);
    z -= 1;
    let x = c[0];
    for (let i = 1; i < c.length; i++) x += c[i] / (z + i);
    const t = z + 7.5;
    return 0.5 * Math.log(2 * Math.PI) + (z + 0.5) * Math.log(t) - t + Math.log(x);
  }

  // Height of the Beta(a, b) curve at p = x. Outside 0 to 1, the height is 0.
  function betaDensity(x, a, b) {
    if (!(x > 0 && x < 1)) return 0;
    const logB = logGamma(a) + logGamma(b) - logGamma(a + b);
    const density = Math.exp((a - 1) * Math.log(x) + (b - 1) * Math.log(1 - x) - logB);
    return Number.isFinite(density) ? density : 0;
  }

  // Points on that curve, from p near 0 to p near 1.
  function betaCurve(a, b) {
    return Array.from({length: 401}, (_, i) => {
      const p = i / 400;
      const x = Math.min(1 - 1e-6, Math.max(1e-6, p));
      return {p, density: betaDensity(x, a, b)};
    });
  }

  // Three decimals, unless the last digit is 0. Then two decimals is enough.
  function formatMean(x) {
    const three = x.toFixed(3);
    return three.endsWith("0") ? x.toFixed(2) : three;
  }

  const curves = priors.map(prior => {
    const postAlpha = prior.alpha + passes;
    const postBeta = prior.beta + failures;
    return {
      ...prior,
      mean: postAlpha / (postAlpha + postBeta),
      curve: betaCurve(postAlpha, postBeta)
    };
  });

  const plot = Plot.plot({
    width: Math.max(280, width - 4),
    height: 360,
    marginTop: 16,
    marginRight: 16,
    marginBottom: 48,
    marginLeft: 52,
    x: {
      label: "Population proportion, p",
      domain: [0, 1],
      ticks: [0, 0.2, 0.4, 0.6, 0.8, 1]
    },
    y: {label: null, grid: true, nice: true},
    marks: [
      ...curves.map(d => Plot.line(d.curve, {
        x: "p",
        y: "density",
        stroke: d.stroke,
        strokeWidth: 2.25,
        strokeDasharray: d.dash
      })),
      Plot.ruleY([0])
    ],
    style: {
      background: "transparent",
      color: "#15151E",
      fontFamily: "Helvetica, sans-serif",
      fontSize: "13px"
    }
  });

  const means = curves.map(d => `${d.name} ${formatMean(d.mean)}`).join(", ");

  return html`<div class="binomial-figure">
    <p class="binomial-ylabel">Density</p>
    ${plot}
    <p class="binomial-readout">This sample has <strong>${passes}</strong> passes out of <strong>${n}</strong>, a rate of <strong>${rate.toFixed(2)}</strong>. The posterior means are <strong>${means}</strong>.</p>
    <p class="binomial-legend"><span class="swatch swatch-other" style="margin-left:0"></span> Lower-pass <span class="swatch swatch-max"></span> Neutral <span class="swatch swatch-observed"></span> Higher-pass</p>
  </div>`;
}
