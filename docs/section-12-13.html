The Posterior Mean and Shrinkage

After finding the entire posterior distribution, we may want a single value that summarizes our updated estimate of \(p\). One common Bayesian estimate is the posterior mean.

The posterior mean is the average of all possible values of \(p\) under the posterior distribution, weighted by how plausible each value is after observing the data. It can be interpreted as our updated point estimate of the proportion of movies that pass the Bechdel test.

For a Beta(\(a\), \(b\)) posterior, the posterior mean is:

\[ E(p \mid y) = \frac{a}{a + b} \]

Using the lower-pass prior, we obtained:

\[ p \mid y \sim \text{Beta}(12, 18) \]

Therefore:

\[ E(p \mid y) = 12/(12 + 18) = 12/30 = 0.40 \]

Based on this prior and the observed sample, our posterior estimate is that 40% of comparable movies pass the Bechdel test.

The sample proportion was:

\[ y/n = 9/20 = 0.45 \]

However, the posterior mean is 0.40. Why is the posterior estimate lower than the sample proportion?

The Beta(3, 7) prior had a mean of:

\[ 3/(3 + 7) = 0.30 \]

The posterior mean falls between the prior mean of 0.30 and the sample proportion of 0.45. It has moved away from the sample proportion and toward the prior mean. This movement is called shrinkage.

In Bayesian statistics, shrinkage occurs when the posterior estimate is pulled toward the prior estimate. The amount of shrinkage depends on the relative amount of information represented by the prior and the data.

The posterior mean can be written as:

\[ E(p \mid y) = \frac{\alpha + \beta}{\alpha + \beta + n} \times \frac{\alpha}{\alpha + \beta} + \frac{n}{\alpha + \beta + n} \times \frac{y}{n} \]

This shows that the posterior mean is a weighted average of:

  • Prior mean = \(\alpha/(\alpha + \beta)\)
  • Sample proportion = \(y/n\)

For the Beta(3, 7) prior:

\[ \alpha + \beta = 3 + 7 = 10 \]

The value \(\alpha + \beta\) is called the prior concentration. In this conjugate model, it controls how much influence the prior has relative to the sample.

The two weights are:

\[ \text{Prior weight} = 10/(10 + 20) = 10/30 \approx 0.333 \]

\[ \text{Data weight} = 20/(10 + 20) = 20/30 \approx 0.667 \]

Therefore:

\[ E(p \mid y) = \frac{10}{30}(0.30) + \frac{20}{30}(0.45) = 0.10 + 0.30 = 0.40 \]

The prior receives about 33.3% of the weight, while the observed sample receives about 66.7%.

Why do the posterior mean and shrinkage matter?

The posterior mean gives us one understandable number with which to summarize the posterior distribution. Instead of describing every possible value of \(p\), we can report 0.40 as our updated point estimate under this particular prior and model.

Shrinkage shows that Bayesian estimation does not simply replace the prior with the sample result. It balances the starting information with the new evidence. This can prevent a small or unusual sample from completely determining the estimate.

However, shrinkage also makes the choice of prior important. A strongly concentrated prior can pull the posterior estimate substantially toward the prior mean, especially when the sample is small. This is why we should justify our prior and compare results under multiple reasonable priors.

If we observed more movies while keeping the same prior, \(n\) would increase and the data would receive more weight. The posterior mean would then move closer to the observed sample proportion. If we used a more concentrated prior while keeping the sample size fixed, the prior would receive more weight and produce greater shrinkage toward its mean.

Move the sample size and the prior concentration. The bars show how the weight splits between the prior and the data. The lower graph keeps the prior mean at 0.30 and the sample proportion at 0.45, and shows the posterior mean move between them.

// Sample size, with the pass rate held at the observed 0.45
viewof n = Inputs.range([1, 200], {
  label: "Sample size, n",
  value: 20,
  step: 1
})
// Prior concentration for a prior whose mean stays at 0.30
viewof concentration = Inputs.range([1, 80], {
  label: "Prior concentration, α + β",
  value: 10,
  step: 1
})
// Prior and data weights, and the posterior mean they produce
{
  const priorMean = 0.30;
  const sampleProportion = 0.45;
  const priorWeight = concentration / (concentration + n);
  const dataWeight = n / (concentration + n);
  const posteriorMean = priorWeight * priorMean + dataWeight * sampleProportion;

  function formatMean(x) {
    const three = x.toFixed(3);
    return three.endsWith("0") ? x.toFixed(2) : three;
  }

  const weights = [
    {name: "Prior", weight: priorWeight},
    {name: "Data", weight: dataWeight}
  ];
  const estimates = [
    {name: "Prior mean", value: priorMean},
    {name: "Posterior mean", value: posteriorMean},
    {name: "Sample proportion", value: sampleProportion}
  ];

  const weightPlot = Plot.plot({

    marginBottom: 40,
    marginLeft: 52,

    marks: [
      Plot.barY(weights, {
        x: "name",
        y: "weight",

      background: "transparent",
      color: "#15151E",
      fontFamily: "Helvetica, sans-serif",

From a Point Estimate to a Posterior Distribution

The posterior mean provides one summary of the posterior, but Bayesian inference does not reduce the answer to a single number.

Under the lower-pass prior:

\[ p \mid y \sim \text{Beta}(12, 18) \]

The full Beta(12, 18) distribution describes the remaining uncertainty about \(p\) after observing the movies.

An approximate 95% credible interval is:

\[ (0.235,\ 0.577) \]

The Bayesian interpretation is: given the Beta(3, 7) prior, the Binomial model, its assumptions, and the observed data, there is approximately a 95% posterior probability that \(p\) lies between 0.235 and 0.577.

This is different from the confidence-interval interpretation. A credible interval makes a probability statement about the unknown parameter, conditional on the model and prior.

The posterior can also answer questions about meaningful thresholds. For example:

\[ P(p < 0.50 \mid y) \approx 0.868 \]

Under this prior and model, there is approximately an 86.8% posterior probability that fewer than half of comparable movies pass.

This statement cannot be separated from its assumptions. It would be incomplete to report “there is an 86.8% probability” without identifying the prior, likelihood, population, and data on which that probability depends.

Move the threshold, and choose whether to shade below it or above it. The shaded area is a posterior probability under Beta(12, 18), the lower-pass posterior.

viewof threshold = Inputs.range([0, 1], {
  label: "Threshold",
  value: 0.50,
  step: 0.01
})
viewof side = Inputs.radio(["Below", "Above"], {
  label: "Shade",
  value: "Below"
})
// Posterior probability on one side of a chosen threshold
{
  const postAlpha = 12;
  const postBeta = 18;

  function logGamma(z) {
    const c = [
      0.99999999999980993,
      676.5203681218851,
      -1259.1392167224028,
      771.32342877765313,
      -176.61502916214059,
      12.507343278686905,
      -0.13857109526572012,
      9.9843695780195716e-6,
      1.5056327351493116e-7
    ];
    if (z < 0.5) return Math.log(Math.PI / Math.sin(Math.PI * z)) - logGamma(1 - z);
    z -= 1;
    let x = c[0];
    for (let i = 1; i < c.length; i++) x += c[i] / (z + i);
    const t = z + 7.5;
    return 0.5 * Math.log(2 * Math.PI) + (z + 0.5) * Math.log(t) - t + Math.log(x);
  }

  function betaDensity(x, a, b) {
    if (!(x > 0 && x < 1)) return 0;
    const logB = logGamma(a) + logGamma(b) - logGamma(a + b);
    const density = Math.exp((a - 1) * Math.log(x) + (b - 1) * Math.log(1 - x) - logB);
    return Number.isFinite(density) ? density : 0;
  }

  // For integer a and b, the Beta(a, b) cdf equals a binomial sum.
  function betaCDF(x, a, b) {
    if (x <= 0) return 0;
    if (x >= 1) return 1;
    const total = a + b - 1;
    let sum = 0;
    for (let k = a; k <= total; k++) {
      let logCoefficient = 0;
      for (let i = 0; i < k; i++) logCoefficient += Math.log(total - i) - Math.log(i + 1);
      sum += Math.exp(logCoefficient + k * Math.log(x) + (total - k) * Math.log(1 - x));
    }
    return Math.min(1, Math.max(0, sum));
  }

  const curve = Array.from({length: 201}, (_, i) => {
    const p = i / 200;
    const x = Math.min(1 - 1e-6, Math.max(1e-6, p));
    return {p, density: betaDensity(x, postAlpha, postBeta)};
  });
  const edge = {
    p: threshold,
    density: betaDensity(Math.min(1 - 1e-6, Math.max(1e-6, threshold)), postAlpha, postBeta)
  };
  const shaded = side === "Below"
    ? [...curve.filter(d => d.p < threshold), edge]
    : [edge, ...curve.filter(d => d.p > threshold)];
  const probability = side === "Below"
    ? betaCDF(threshold, postAlpha, postBeta)
    : 1 - betaCDF(threshold, postAlpha, postBeta);
  const percent = probability * 100;
  const percentText = percent >= 1
    ? `${percent.toFixed(1)}%`
    : percent >= 0.01
      ? `${percent.toFixed(2)}%`
      : percent > 0
        ? "< 0.01%"
        : "0%";
  const relation = side === "Below" ? "below" : "above";

  const plot = Plot.plot({
    width: Math.max(280, width - 4),
    height: 360,
    marginTop: 16,
    marginRight: 16,
    marginBottom: 48,
    marginLeft: 52,
    x: {
      label: "Population proportion, p",
      domain: [0, 1],
      ticks: [0, 0.2, 0.4, 0.6, 0.8, 1]
    },
    y: {label: null, grid: true, nice: true},
    marks: [
      Plot.areaY(shaded, {
        x: "p",
        y: "density",
        fill: "#b32b2f",
        fillOpacity: 0.18,
        curve: "linear"
      }),
      Plot.line(curve, {
        x: "p",
        y: "density",
        stroke: "#2c3140",
        strokeWidth: 2.25
      }),
      Plot.ruleX([threshold], {
        stroke: "#b32b2f",
        strokeWidth: 2
      }),
      Plot.ruleY([0])
    ],
    style: {
      background: "transparent",
      color: "#15151E",
      fontFamily: "Helvetica, sans-serif",
      fontSize: "13px"
    }
  });

  return html`<div class="binomial-figure">
    <p class="binomial-ylabel">Density</p>
    ${plot}
    <p class="binomial-readout">Under the Beta(12, 18) posterior, the probability that <em>p</em> is ${relation} ${threshold.toFixed(2)} is <strong>${percentText}</strong>.</p>
    <p class="binomial-legend"><span class="swatch swatch-other" style="margin-left:0"></span> Posterior <span class="swatch swatch-observed"></span> Probability ${relation} the threshold</p>
  </div>`;
}
