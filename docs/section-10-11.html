Updating with Bayes’ Rule

Last updated

October 14, 2026

Now we reach the central step of Bayesian inference: combining our prior beliefs with the movie data to produce an updated distribution for \(p\).

The general form of Bayes’ rule is:

\[ f(p \mid y) = \frac{f(y \mid p)\, f(p)}{f(y)} \]

This can be summarized as:

\[ \text{Posterior} \propto \text{Likelihood} \times \text{Prior} \]

Here:

  • The prior describes our uncertainty about \(p\) before observing the sample.
  • The likelihood describes how compatible the observed data are with different values of \(p\).
  • The posterior describes our updated uncertainty about \(p\) after observing the sample.

Updating a Beta prior

The likelihood for the 9 passing and 11 failing movies is:

\[ L(p \mid y) \propto p^{9}(1 - p)^{11} \]

A Beta prior has the following kernel:

\[ f(p) \propto p^{\alpha - 1}(1 - p)^{\beta - 1} \]

When we multiply the likelihood and prior, we obtain:

\[ f(p \mid y) \propto p^{9}(1 - p)^{11} \times p^{\alpha - 1}(1 - p)^{\beta - 1} \]

Combining terms with the same base gives:

\[ f(p \mid y) \propto p^{\alpha + 9 - 1}(1 - p)^{\beta + 11 - 1} \]

This has the same form as another Beta distribution. Therefore:

\[ p \mid y \sim \text{Beta}(\alpha + 9,\ \beta + 11) \]

More generally, if \(y\) movies pass out of \(n\) movies:

\[ p \mid y \sim \text{Beta}(\alpha + y,\ \beta + n - y) \]

The update has a memorable structure:

  • Posterior \(\alpha\) = prior \(\alpha\) + observed passes
  • Posterior \(\beta\) = prior \(\beta\) + observed failures

This calculation shows exactly how Bayesian learning occurs. Each observed pass adds to the first parameter, while each observed failure adds to the second. The resulting posterior combines our starting assumptions with the evidence from the sample.

What is conjugacy?

In general, a prior distribution is called conjugate to a likelihood when the resulting posterior belongs to the same family of distributions as the prior. The parameter values change after observing the data, but the type of distribution does not.

In this setting, the Beta distribution is conjugate to the Binomial likelihood. We begin with a Beta prior for \(p\), use a Binomial model for the number of passing movies, and obtain another Beta distribution as the posterior:

\[ \text{Beta prior} + \text{Binomial likelihood} \rightarrow \text{Beta posterior} \]

For example, if we begin with the uniform prior:

\[ p \sim \text{Beta}(1, 1) \]

then observing 9 passes and 11 failures produces:

\[ p \mid y \sim \text{Beta}(1 + 9,\ 1 + 11) \]

\[ p \mid y \sim \text{Beta}(10, 12) \]

Conjugacy is convenient because it allows us to update the prior by changing only its parameters. Because the posterior remains a Beta distribution, we can easily estimate \(p\), construct credible intervals, and calculate probabilities such as:

\[ P(p < 0.50 \mid \text{data}) \]

Conjugacy is a computational convenience, not evidence that a particular prior is appropriate. We must still explain why the prior is reasonable and examine whether different prior choices meaningfully change our conclusions.

Three Priors Meet the Same Data

The same update now meets the three moviegoers. All three observe the same evidence: 9 passes and 11 failures.

The lower-pass viewpoint

The first moviegoer began with:

\[ p \sim \text{Beta}(3, 7) \]

Adding the 9 passes and 11 failures gives:

\[ p \mid y \sim \text{Beta}(3 + 9,\ 7 + 11) = \text{Beta}(12, 18) \]

The prior mean was \(3/10 = 0.30\). The posterior mean is:

\[ E(p \mid y) = 12/(12 + 18) = 0.40 \]

The neutral viewpoint

The second moviegoer is the uniform case above:

\[ p \sim \text{Beta}(1, 1) \]

\[ p \mid y \sim \text{Beta}(10, 12) \]

The posterior mean is:

\[ E(p \mid y) = 10/(10 + 12) = 10/22 \approx 0.455 \]

The higher-pass viewpoint

The third moviegoer began with:

\[ p \sim \text{Beta}(7, 3) \]

\[ p \mid y \sim \text{Beta}(7 + 9,\ 3 + 11) = \text{Beta}(16, 14) \]

The prior mean was \(7/10 = 0.70\). The posterior mean is:

\[ E(p \mid y) = 16/(16 + 14) = 16/30 \approx 0.533 \]

The data pulls all three people toward the observed pass rate of 0.45. The sample is not large enough to erase their initial disagreement.

The lower-pass moviegoer moves upward from a prior mean of 0.30. The posterior mean, 0.40, remains below the sample proportion.

The neutral moviegoer lets the sample dominate. Beta(1, 1) has concentration \(\alpha + \beta = 2\), so the posterior mean, about 0.455, stays close to 0.45.

The higher-pass moviegoer moves downward from a prior mean of 0.70. The posterior mean, about 0.533, is still above 0.45.

Choose a viewpoint. The graph shows that prior, the likelihood from these 20 movies, and the posterior that combines them. The likelihood is drawn with area 1, so it can sit on the same scale as the two Beta densities. On that scale it is a Beta(10, 12) curve.

// Which of the three moviegoers to update
viewof viewpoint = Inputs.radio(
  ["Lower-pass", "Neutral", "Higher-pass"],
  {label: "Viewpoint", value: "Lower-pass"}
)
// Prior, area-1 likelihood, and posterior for the selected viewpoint
{
  const passes = 9;
  const failures = 11;
  const priors = {
    "Lower-pass": {alpha: 3, beta: 7},
    "Neutral": {alpha: 1, beta: 1},
    "Higher-pass": {alpha: 7, beta: 3}
  };

  // Gamma(n) = (n - 1)! for a whole number n: 1 × 2 × ... × (n - 1).
  // The three posteriors are Beta(12, 18), Beta(10, 12), and Beta(16, 14).
  // The largest gamma value is Gamma(30), which JavaScript can store.
  function gamma(n) {
    let value = 1;
    for (let k = 2; k < n; k++) value *= k;
    return value;
  }

  // Height of the Beta(a, b) curve at p = x. Outside 0 to 1, the height is 0.
  // B(a, b) = Gamma(a) Gamma(b) / Gamma(a + b).
  function betaDensity(x, a, b) {
    if (!(x > 0 && x < 1)) return 0;
    const B = gamma(a) * gamma(b) / gamma(a + b);
    const density = (x ** (a - 1)) * ((1 - x) ** (b - 1)) / B;
    return Number.isFinite(density) ? density : 0;
  }

  // Points on that curve, from p near 0 to p near 1.
  // Again, similar to previous sections 
  // Curve drawn as 201 dots 
  // which are evenly spaced from p = 0 to p = 1.
  // The height is calculated a tiny step inside (0, 1), so we never take a power of exactly 0.
  function betaCurve(a, b) {
    return Array.from({length: 201}, (_, i) => {
      const p = i / 200;
      const x = Math.min(1 - 1e-6, Math.max(1e-6, p));
      return {p, density: betaDensity(x, a, b)};
    });
  }

  // Three decimals, unless the last digit is 0. Then two decimals is enough.
  function formatMean(x) {
    const three = x.toFixed(3);
    return three.endsWith("0") ? x.toFixed(2) : three;
  }

  // A Beta prior plus binomial data stays Beta.
  // Passes add to alpha. Failures add to beta.
  const prior = priors[viewpoint];
  const postAlpha = prior.alpha + passes;
  const postBeta = prior.beta + failures;
  const priorMean = prior.alpha / (prior.alpha + prior.beta);
  const posteriorMean = postAlpha / (postAlpha + postBeta);
  // p^9 (1-p)^11, normalized, is the Beta(10, 12) density.
  const likelihood = betaCurve(passes + 1, failures + 1);
  const priorCurve = betaCurve(prior.alpha, prior.beta);
  const posteriorCurve = betaCurve(postAlpha, postBeta);
  const coincides = prior.alpha === 1 && prior.beta === 1;

  const plot = Plot.plot({
    width: Math.max(280, width - 4),
    height: 360,
    marginTop: 16,
    marginRight: 16,
    marginBottom: 48,
    marginLeft: 52,
    x: {
      label: "Population proportion, p",
      domain: [0, 1],
      ticks: [0, 0.2, 0.4, 0.6, 0.8, 1]
    },
    y: {label: null, grid: true, nice: true},
    marks: [
      Plot.areaY(posteriorCurve, {
        x: "p",
        y: "density",
        fill: "#b32b2f",
        fillOpacity: 0.12,
        curve: "linear"
      }),
      Plot.line(priorCurve, {
        x: "p",
        y: "density",
        stroke: "#2c3140",
        strokeWidth: 2.25
      }),
      Plot.line(posteriorCurve, {
        x: "p",
        y: "density",
        stroke: "#b32b2f",
        strokeWidth: 2.25
      }),
      Plot.line(likelihood, {
        x: "p",
        y: "density",
        stroke: "#5c5660",
        strokeWidth: 2.25,
        strokeDasharray: "4,3"
      }),
      Plot.ruleY([0])
    ],
    style: {
      background: "transparent",
      color: "#15151E",
      fontFamily: "Helvetica, sans-serif",
      fontSize: "13px"
    }
  });

  const match = coincides
    ? " The flat prior lets the posterior match the scaled likelihood."
    : "";

  return html`<div class="binomial-figure">
    <p class="binomial-ylabel">Density</p>
    ${plot}
    <p class="binomial-readout">The ${viewpoint.toLowerCase()} prior is Beta(${prior.alpha}, ${prior.beta}), with mean <strong>${formatMean(priorMean)}</strong>. After 9 passes and 11 failures, the posterior is Beta(${postAlpha}, ${postBeta}), with mean <strong>${formatMean(posteriorMean)}</strong>.${match}</p>
    <p class="binomial-legend"><span class="swatch swatch-other" style="margin-left:0"></span> Prior <span class="swatch swatch-max"></span> Likelihood, area 1 <span class="swatch swatch-observed"></span> Posterior</p>
  </div>`;
}
